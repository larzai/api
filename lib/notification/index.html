JAVASCRIPT NOTIFICATION LIBRARY

Lycaxia

A lightweight notification system for JavaScript featuring Log, Info, Confirm, Prompt, Toast, Dynamic Island, multi-language support, and sound effects.

Get Started Website
GETTING STARTED
Installation

Lycaxia can be integrated directly via Vanilla JavaScript or installed in React projects.

Vanilla JavaScript

Simply include the script tag at the bottom of your HTML <body> (styles are automatically injected).

HTML 
<script src="https://lib.lycaxia.com/notification/script.js"></script>

npm

Install the package via npm for module bundlers or React apps.

Terminal 
npm install lycaxia-notification
VANILLA JAVASCRIPT

Vanilla Setup

In Vanilla JavaScript environments, Lycaxia auto-injects its styling and exposes the global lyn object.

HTML 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Lycaxia Example</title>
</head>
<body>

  <button onclick="showNotification()">Show Notification</button>

  <script src="https://lib.lycaxia.com/notification/script.js"></script>
  <script>
    lyn.soundNotification("allow");

    function showNotification() {
      lyn.toast({
        Title: "Hello!",
        Mess: "Lycaxia loaded successfully.",
        Status: "success"
      });
    }
  </script>

</body>
</html>

Vanilla Usage

All core notification methods are accessible directly through the lyn object.

lyn.log() Simple bottom notification
lyn.info() Information modal dialog
lyn.confirm() Confirmation modal dialog
lyn.prompt() Promise-based input modal
lyn.toast() Stackable toast notification
lyn.dynamicIsland() Animated Dynamic Island
REACT

React Setup

Import and call lyn methods inside your React event handlers.

JSX 
import lyn from "lycaxia-notification";

function App() {
  function showNotification() {
    lyn.toast({
      Title: "Success",
      Mess: "Hello from React!",
      Status: "success"
    });
  }

  return (
    <button onClick={showNotification}>
      Show Notification
    </button>
  );
}

export default App;

React Usage

Attach methods directly to standard React synthetic events like onClick.

React 
function App() {
  const notify = () => {
    lyn.toast({
      Title: "Data Saved",
      Mess: "Your changes have been saved successfully.",
      Status: "success"
    });
  };

  return (
    <button onClick={notify}>
      Save Changes
    </button>
  );
}
API REFERENCE

API Overview

Comprehensive list of methods available on the lyn instance. Most parameters are optional and fall back to default values automatically if omitted.

Method Description
lyn.log() Displays a subtle status bar at the bottom of the screen.
lyn.info() Displays an informational modal with title and subtitle.
lyn.confirm() Displays a confirmation modal with callback options.
lyn.prompt() Displays an input modal that resolves a JavaScript Promise.
lyn.toast() Displays a toast notification on the top-right screen.
lyn.dynamicIsland() Displays an expandable Dynamic Island banner.
lyn.setLang() Switches the internal system language ("en" or "id").
lyn.soundNotification() Enables or disables sound effects for notifications.

lyn.log()

Displays lightweight log bar notifications at the bottom of the viewport.

lyn.log(options)

Options

Mess Optional
The message text content. Defaults to an empty log line.
Status Optional
Notification state ("default" or "error"). Defaults to "default".
JavaScript 
lyn.log({
  Mess: "Request sent successfully, please wait."
});

lyn.log({
  Status: "error",
  Mess: "Failed to connect to server."
});

lyn.info()

Opens a structured modal dialog containing subtitle, title, and detailed message text.

lyn.info(options)

Options

Subtitle Optional
Header text shown above the main title. Defaults to the system localized subtitle.
Title Optional
Main title text of the modal. Defaults to the system localized title.
Mess Optional
Main message body (supports newlines).
JavaScript 
lyn.info({
  Subtitle: "Lycaxia Demo",
  Title: "Information",
  Mess: "This is an informational dialog from lyn.info.\nSecond line text is also supported."
});

lyn.confirm()

Displays an interactive confirmation dialog with action callbacks.

lyn.confirm(options)

Options

Mess Optional
Confirmation prompt message. Defaults to localized default confirm text.
Event Optional
Callback function or redirect URL executed when "Continue" is clicked.
JavaScript 
lyn.confirm({
  Mess: "Are you sure you want to proceed?",
  Event: function() {
    lyn.log({
      Status: "success",
      Mess: "You pressed Continue."
    });
  }
});

lyn.prompt()

Opens an input modal dialog. Returns a Promise that resolves with user input or rejects if cancelled.

await lyn.prompt(options)

Options

Mess Optional
Input label prompt text. Defaults to localized prompt title.
Type Optional
HTML input field type. Defaults to "text".

Input Types

text number num email url date time tel range password
JavaScript 
async function askNumber() {
  try {
    const number = await lyn.prompt({
      Mess: "Enter your phone number:",
      Type: "num"
    });

    lyn.log({
      Status: "success",
      Mess: "You entered: " + number
    });
  } catch (err) {
    lyn.log({
      Status: "error",
      Mess: "User cancelled the prompt."
    });
  }
}

askNumber();

lyn.toast()

Displays stackable toast notifications at the top-right corner with queued auto-dismissal.

lyn.toast(options)

Options

Title Optional
Toast header title. Defaults to status label or localized text.
Mess Optional
Toast body text content.
Status Optional
Toast status theme. Defaults to "default".
Permanent Optional
If true, the toast will stay until closed manually. Defaults to false.

Status Values

default success ok error err failed
JavaScript 
lyn.toast({
  Title: "Information",
  Mess: "This is a default toast.",
  Status: "default"
});

lyn.toast({
  Title: "Success",
  Mess: "Data saved successfully.",
  Status: "success"
});

lyn.toast({
  Title: "Error",
  Mess: "Server error occurred.",
  Status: "error"
});

lyn.toast({
  Title: "Permanent",
  Mess: "This toast will not auto-dismiss.",
  Status: "default",
  Permanent: true
});

lyn.dynamicIsland()

Displays an interactive Dynamic Island banner with smooth expand and collapse animations.

lyn.dynamicIsland(options)

Options

Status Optional
Defines color accent and status state. Defaults to "default".
Mess Optional
Primary message content.
Label Optional
Built-in icon and preset type. Defaults to "info".
Duration Optional
Display duration in milliseconds.
CustomIcon Optional
Custom SVG or HTML icon string. Requires Label: "custom".
CustomColor Optional
Custom icon accent color. Requires Label: "custom".
CustomAnimation Optional
Custom CSS animation rule. Requires Label: "custom".
JavaScript 
lyn.dynamicIsland({
  Status: "success",
  Mess: "File downloaded successfully",
  Label: "download",
  Duration: 3000
});

Dynamic Island Statuses

Supported status themes for customizing Dynamic Island visuals.

default Default theme
active Active theme
success Success theme
warning Warning theme
failed Error theme
waiting Pending state
JavaScript 
const statuses = [
  { Status: "default", Label: "info", Mess: "Default status" },
  { Status: "active", Label: "info", Mess: "Active status" },
  { Status: "success", Label: "success", Mess: "Success status" },
  { Status: "warning", Label: "warning", Mess: "Warning status" },
  { Status: "failed", Label: "failed", Mess: "Failed status" },
  { Status: "waiting", Label: "wait", Mess: "Waiting status" }
];

statuses.forEach(item => lyn.dynamicIsland(item));

Dynamic Island Icons

Built-in icon choices mapped to the Label parameter.

home notification music info download upload settings success failed warning wait
JavaScript 
const icons = [
  "home", "notification", "music", "info",
  "download", "upload", "settings", "success",
  "failed", "warning", "wait"
];

icons.forEach(icon => {
  lyn.dynamicIsland({
    Status: "default",
    Label: icon,
    Mess: "Icon: " + icon
  });
});

Custom Dynamic Island

Set Label: "custom" to insert custom SVG graphics, colors, and keyframe animations.

JavaScript 
lyn.dynamicIsland({
  Label: "custom",
  Mess: "Custom Dynamic Island!",
  CustomIcon: `
    <svg viewBox="0 0 24 24">
      <path d="M12 2 14.5 9.5 22 12l-7.5 2.5L12 22l-2.5-7.5L2 12l7.5-2.5L12 2Z"/>
    </svg>
  `,
  CustomColor: "#a855f7",
  CustomAnimation: "lyCustomPulse 1s ease-in-out infinite"
});

Custom Animation

Pass custom CSS animation property values and declare keyframe styles in your stylesheet.

JavaScript + CSS 
lyn.dynamicIsland({
  Label: "custom",
  Mess: "Custom pulse animation!",
  CustomIcon: '<svg viewBox="0 0 24 24"><path d="M12 2a10 10 0 1 0 0 20 10 10 0 0 0 0-20Z"/></svg>',
  CustomColor: "#d0e505",
  CustomAnimation: "lyCustomPulse 1s ease-in-out infinite"
});

/*
CSS Keyframes:
@keyframes lyCustomPulse {
  0% { transform: scale(1) rotate(0); }
  50% { transform: scale(1.25) rotate(180deg); }
  100% { transform: scale(1) rotate(360deg); }
}
*/

lyn.setLang()

Switch between supported localization presets (English and Indonesian).

lyn.setLang(language)
en id
JavaScript 
lyn.setLang("en");

lyn.info({
  Mess: "Language is now set to English."
});

lyn.setLang("id");

lyn.info({
  Mess: "Bahasa sekarang menggunakan Indonesia."
});

Localization Keys

subtitle_infoInfo modal subtitle

subtitle_confirmConfirm modal subtitle

prompt_subtitlePrompt subtitle
sendSend button text
byeCompletion message
errorError message
default_titleqrDefault QR title
any_infoCustom button info

lyn.soundNotification()

Controls global sound effects when triggering notifications.

lyn.soundNotification(value)

Supported Values

allow on enable off false true
JavaScript 
lyn.soundNotification("allow");

lyn.toast({
  Title: "Sound ON",
  Mess: "Notification sounds enabled.",
  Status: "success"
});

lyn.soundNotification("off");

lyn.toast({
  Title: "Sound OFF",
  Mess: "Notification sounds disabled."
});
COMPLETE EXAMPLE

Example Project

A full integration example demonstrating multiple Lycaxia notification types together.

HTML 
<button onclick="showToast()">Toast</button>
<button onclick="showConfirm()">Confirm</button>
<button onclick="showDynamic()">Dynamic Island</button>

<script src="https://lib.lycaxia.com/notification/script.js"></script>

<script>
  lyn.soundNotification("allow");

  function showToast() {
    lyn.toast({
      Title: "Lycaxia",
      Mess: "Hello from Lycaxia!",
      Status: "success"
    });
  }

  function showConfirm() {
    lyn.confirm({
      Mess: "Are you sure you want to proceed?",
      Event: function() {
        lyn.log({
          Status: "success",
          Mess: "Proceeded successfully."
        });
      }
    });
  }

  function showDynamic() {
    lyn.dynamicIsland({
      Status: "success",
      Label: "download",
      Mess: "Download finished!",
      Duration: 3000
    });
  }
</script>
